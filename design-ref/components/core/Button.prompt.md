Innovic action button — use for every clickable action; one primary per toolbar, top-right.
```jsx
<Button variant="primary">+ New SO / WO</Button>
<Button variant="ghost" size="sm">Export</Button>
<Button variant="danger" size="sm">Del</Button>
<Button variant="primary" pill>All</Button>
```
Variants: primary, success, danger, ghost. Sizes: md (13px), sm (11px). `pill` = status-filter chip. `iconOnly` for row actions (Eye / Pencil / Trash2 at 13px).
